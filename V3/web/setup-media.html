📡 OBS connection (for “OBS Source” slides)

Camera, window and game capture stay in OBS. A Media List item of type “OBS Source” turns that OBS source on while its slide is showing, and off again when the slide changes.

—
In OBS: Tools → WebSocket Server Settings → tick Enable WebSocket server → Show Connect Info to copy the port and password. This is saved right away (not with 💾 Save) and stays on this computer.

📁 Media files

Files you pick with 📁 or drop on the lists are copied into the program's media folder, so copying the whole SlideMang folder to another computer takes every file and setting with it.
