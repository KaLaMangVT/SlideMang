❓ How to / Shortcuts

⌨ Shortcuts (Active when ⌨ switch in menu bar is ON)
  • Q Prev Image · W Show/Hide Image · E Next Image · Space Play/Pause Video (for Media)
  • A Prev Titlebar · S Show/Hide Titlebar · D Next Titlebar (for Titlebar)
  • Z Prev Background · X Show/Hide Background · C Next Background · V Play/Pause Video (for Background)
  • Supports actual key codes, works even with Thai keyboard layout enabled · Does not work while typing in text boxes.
🧰 Menu Bar
  • ℹ️ Credits · ⌨ Toggle Shortcuts · 💾 Save to data/controller-save.json · 📂 Load from data/controller-save.json · ↺ Reset Default
  • 🖼️ Media / 📰 Titlebar / 🌌 Background Toggle panel groups
  • Everything is saved automatically and shared by every open Controller (app, browser, phone).
  • 🔄 OBS reloads every OBS display window and Browser Source · 🗜 Compact mode for a small window
🖼️ Media Control / Quick Panel
  • PREV / NEXT Change image · Show/Hide Hide or display image on screen
  • Auto Slide Automatically change image based on specified seconds
  • 🎬 Toggle Video Controller: Play / Stop / Loop · Timeline · Volume bar · Stop on Hide
  • Quick Panel: Click card to jump to that image · Dir = Transition effect · BG 1–3 / Transparent
📰 Title Bar Control
  • Show/Hide Toggle Titlebar · Update Send edited values to screen
  • Real Time Type Header/Body and update screen instantly · Instant Switch (Select preset and update screen instantly)
  • Dir = Transition effect when opening/closing/switching Titlebar
  • Background Image: Enter file name in media folder, uses design color if empty
🌌 Background Control
  • Z / X / C / V Control next background/show-hide/play background video
  • Supports switching Background Presets from video or static image
