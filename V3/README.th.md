# SlideMang v3 (Portable)

โปรแกรมเดียว เลือกภาษาได้ ประกอบด้วย Controller, Setup Media, หน้าต่างแสดงผลสำหรับ OBS และเซิร์ฟเวอร์ในตัว
v3 เป็นเวอร์ชันหลักนับจากนี้ แยกอิสระจากเวอร์ชันเก่า (`../APP`, `../WEB`) ซึ่งเก็บไว้ตามเดิม

## มีอะไรใหม่
- **โค้ดชุดเดียว เลือกภาษาได้** (ค่าเริ่มต้น English มีภาษาไทย) เปลี่ยนได้จาก Launcher, แถบเมนู Controller หรือหน้า Setup Media
  เพิ่มภาษา: ก๊อป `locales/th.json` เป็น `locales/<รหัสภาษา>.json` แก้ `_meta.name` แล้วแปลค่า (key เป็นภาษาอังกฤษ ห้ามแก้)
  วางโฟลเดอร์ `locales` ไว้ข้าง `SlideMang.exe` ก็ใช้ได้ ไม่ต้อง build ใหม่
- **Portable**: `data/` และ `media/` อยู่ข้าง `SlideMang.exe` ก๊อปทั้งโฟลเดอร์ไปเครื่องอื่นได้ทันที พร้อมไฟล์และการตั้งค่า
- **Setup Media**
  - เปิดแล้วโหลดค่าปัจจุบันเอง กด **💾 บันทึก** (หรือ Ctrl+S) เขียนทับ `data/config.json` ทันที (เก็บสำรอง `.bak` ไว้ 1 ชุด)
  - ปุ่ม 📁 ข้างช่องไฟล์ จะ **ก๊อปไฟล์เข้า `media/`** (หรือโฟลเดอร์ย่อยที่เลือกในแถบด้านบน)
  - **ลากไฟล์มาวาง** ที่รายการ Media / Background → ก๊อปเข้า `media/` และสร้างรายการให้อัตโนมัติ
  - **📥 เพิ่มไฟล์…** เพิ่มหลายไฟล์พร้อมกัน, **+ สร้างโฟลเดอร์** สำหรับแยกหัวข้อ
  - เช็คพื้นที่ดิสก์ก่อนก๊อป ถ้าไม่พอจะแจ้งเตือนและไม่ก๊อปเลย
  - ไฟล์เดิมซ้ำจะไม่ก๊อปซ้ำ ถ้าชื่อซ้ำแต่คนละไฟล์จะตั้งชื่อเป็น `name (2).ext`
  - ไฟล์ที่ไม่มีใน `media/` จะขึ้นเครื่องหมาย ⚠
  - **↺ รีเซ็ตค่าเริ่มต้น** โหลดตัวอย่างหัวข้อละ 1 รายการ (มีรูปตัวอย่างให้)
  - ลากเลือกข้อความในช่องพิมพ์ จะไม่ไปย้ายลำดับรายการแล้ว (ย้ายได้เฉพาะจับที่ ⠿)
- **ทุกหน้าจอตรงกัน**
  - กดบันทึกใน Setup Media แล้ว Controller และจอ OBS อัปเดตทันที
  - ปุ่ม **🔄 รีเฟรช OBS** (ใน Launcher และ Controller) รีโหลด OBS Titlebar / Slides / Background ทั้งหน้าต่างในแอปและ Browser Source ใน OBS
  - Controller ทุกหน้าที่เปิด (แอป เบราว์เซอร์ มือถือ) ใช้สถานะเดียวกัน: ภาพปัจจุบัน แสดง/ซ่อน titlebar เสียง ฯลฯ
  - **Auto Slide นับเวลาที่ตัวโปรแกรมที่เดียว** เปิด Controller หลายหน้าก็ไม่เปลี่ยนเร็วขึ้น และยังทำงานแม้ปิด Controller
  - สถานะบันทึกอัตโนมัติที่ `data/session.json` (ปุ่ม 📁/💾 ใน Controller กลายเป็นนำเข้า/ส่งออก)
  - การเปิด/ปิดกลุ่ม panel จำแยกตามเครื่อง
- **สไลด์แบบ OBS Source** (กล้อง / จับภาพหน้าต่าง / เกม): การจับภาพยังอยู่ใน OBS ตามเดิม SlideMang จะเปิด source ที่เลือกใน OBS ขณะที่สไลด์นั้นแสดง และปิดเมื่อเปลี่ยนสไลด์หรือซ่อน Media (ใช้ obs-websocket ที่มีในตัว OBS 28 ขึ้นไป) ตั้งค่าที่ Setup Media → ทั่วไป → เชื่อมต่อ OBS แล้วกด **📡 เพิ่ม OBS Source** ใน Media List ส่วน source อื่นที่ SlideMang ไม่ได้ใช้จะไม่ถูกแตะ
- **สไลด์กล้อง และจับภาพหน้าต่าง / หน้าจอ** ในตัว SlideMang (📷 เพิ่มกล้อง / 🖥 เพิ่มจับภาพหน้าจอ) จะเปิดอุปกรณ์เฉพาะตอนที่สไลด์นั้นออนแอร์และ Media แสดงอยู่ แล้วปิดทันทีเมื่อเลิกใช้ คนที่ใช้แค่ภาพ/วิดีโอจึงไม่เสียทรัพยากรเพิ่ม เลือกกล้องจากชื่อ ความละเอียด FPS กลับด้าน; เลือกหน้าต่างจากภาพตัวอย่าง (จับคู่จากชื่อหน้าต่าง) หรือทั้งหน้าจอ; ตัดขอบเป็น % ระหว่างออนแอร์ Controller มีแผงปรับสด เปลี่ยนกล้อง/หน้าต่าง กลับด้าน การขยาย ตัดขอบ และ 💾 บันทึกลง Setup ทำงานในหน้าต่างแสดงผลของ SlideMang (ให้ OBS จับด้วย Window Capture) Browser Source ของ OBS เปิดอุปกรณ์ไม่ได้ ถ้า OBS ใช้กล้องตัวเดียวกันอยู่ จะใช้ได้ทีละโปรแกรม
- **ส่งภาพสดต่อ (WebRTC)**: Browser Source ของ OBS และจอที่เปิดผ่าน Network เปิดกล้องหรือจับภาพหน้าจอของเครื่องนี้เองไม่ได้ SlideMang จึงส่งวิดีโอไปให้แทน หน้าต่างทำงานเบื้องหลัง (ซ่อนอยู่) จะเริ่มก็ต่อเมื่อมีจอแบบนี้แสดงสไลด์กล้อง/จับภาพ เปิดอุปกรณ์ แล้วส่งภาพผ่านวง LAN (หน่วงต่ำ สูงสุด 8 Mbps) และปิดตัวเอง 30 วินาทีหลังไม่มีคนดู ส่วนหน้าต่างแสดงผลของ SlideMang ยังเปิดอุปกรณ์เองเหมือนเดิม (ประหยัดที่สุดเมื่อใช้ Window Capture ในเครื่องเดียวกัน) เปิด/ปิดได้ที่ Setup Media → ทั่วไป ใช้กับ OBS อีกเครื่อง หรือใช้ Browser Source แทน Window Capture
- **OBS Scenes**: แยกเป็นรายการของตัวเอง **OBSSCENE_LIST** (Setup Media → 🎬 OBS Scenes) แต่ละรายการคือปุ่มในแผง 🎬 OBS Scenes ของ Controller มีชื่อปุ่ม, Scene และ Transition + ระยะเวลาของตัวเอง (ใช้เฉพาะตอนกดแล้วคืนค่า Transition เดิมของ OBS) Scene เดียวกันจึงมีได้หลายปุ่ม ปุ่มที่ออนแอร์จะไฮไลต์และตามการเปลี่ยนจากใน OBS ถ้าไม่มีรายการ แผงจะแสดงทุก Scene ใน OBS การเปลี่ยน Scene มีที่นี่ที่เดียว (ไม่อยู่ใน Media หรือ Background List)
- **Background List** ใส่ 📷 กล้อง, 🖥 จับภาพหน้าต่าง/หน้าจอ และ 📡 OBS Source (แบบสไลด์หรือ Toggle) ได้ด้วย ทำงานเฉพาะตอนใช้ และส่งภาพต่อผ่าน WebRTC ได้เหมือน Media List
- **OBS Source มี 2 แบบ**: *สไลด์* (ค่าเริ่มต้น) — แสดงทีละอย่างร่วมกับภาพ/วิดีโอ/กล้อง; *Toggle* — กดการ์ดเพื่อเปิด/ปิด source นั้นใน OBS แยกอิสระ ไม่เปลี่ยนสไลด์ และ PREV/NEXT/Auto Slide จะข้ามไป ตัว Toggle จะไม่ถูกแตะจนกว่าจะกด และการ์ดแสดงสถานะจริงใน OBS
- **หน้าต่างเล็ก**: แก้การแสดงผลตอนย่อจอ และมี **🗜 โหมดกะทัดรัด** ใน Controller
- **เกี่ยวกับ**: ลิงก์ GitHub, Donate และ YouTube (Launcher → เกี่ยวกับ, Controller → ℹ️) ตั้งค่าที่ `package.json` → `slidemang.links`
- Electron 45, ไม่มี dependency ตอนรัน, ไม่ใช้ `eval` ในหน้าเว็บ, API ที่แก้ไขข้อมูลกันเว็บอื่นเรียกใช้

## รัน / build
1. Node.js 22 LTS ขึ้นไป
2. ในโฟลเดอร์นี้: `npm install`
3. ทดสอบ: `npm start` · ทดสอบโค้ด: `npm test`
4. สร้าง exe แบบ portable: `npm run dist` → `dist/SlideMang.exe` (หรือ `npm run dist:zip`)

ถ้า `npm run dist` มีปัญหากับ path ภาษาไทย ให้ย้ายโปรเจกต์ไปไว้ใน path ภาษาอังกฤษ
